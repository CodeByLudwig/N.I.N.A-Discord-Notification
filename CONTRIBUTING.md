# Contributing Guidelines

Thank you for considering contributing to this project!

## How to Contribute

- Fork the repository and create your branch from `develop`.
- Make sure your code builds and passes existing tests.
- Write clear, concise commit messages.
- For bigger changes, please open an issue first to discuss your idea.

## Code Style

- Follow existing code style and conventions.
- Add comments where helpful.

## Pull Requests

- Describe your changes and reference related issues if applicable.
- Make sure your PR is based on the latest `develop` branch.

---

If you have questions, feel free to open an issue or contact the maintainers.
