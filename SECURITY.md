# Security Policy

## Supported Versions

The table below shows which major versions of this project are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |
| < 1.0   | :x:                |

We provide security updates and critical fixes only for the latest 2.x release. Please always use the most recent 2.x version to stay secure.

## Reporting a Vulnerability

If you find a security vulnerability, please report it responsibly.

- **Do not open public issues for security matters**.
- Contact the maintainers privately via a [GitHub security advisory](https://github.com/CodeByLudwig/N.I.N.A-Discord-Notification/security/advisories) or by direct message (e.g., Discord: Daniel1109#1149).
- You can expect an initial response within a few days.
- We’ll keep you informed about the status and resolution of your report.

Thank you for helping to keep this project and its users secure!
